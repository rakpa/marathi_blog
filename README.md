# विद्या (Vidya) — एक मराठी ज्ञान-मासिक

> **जगातलं उत्तम ज्ञान — तुमच्या भाषेत.**
> महत्त्वाकांक्षी, जिज्ञासू मराठी वाचकांसाठी व्यवसाय, तंत्रज्ञान, स्टार्टअप, कौशल्ये,
> उद्योजकता आणि करिअर यांवरचं विश्वासार्ह, सखोल आणि उपयुक्त डिजिटल मासिक.

विद्या हे क्लिकबेट नाही, गोंगाट नाही. **दर्जा, संख्येपेक्षा महत्त्वाचा** — हेच मुख्य तत्त्व.
प्रत्येक लेख वाचकाला अधिक हुशार, अधिक सक्षम किंवा अधिक माहितीपूर्ण बनवतो.

## तंत्रज्ञान स्टॅक

| क्षेत्र | निवड | कारण |
|---|---|---|
| Framework | **[Astro](https://astro.build) 5** | कंटेंट-केंद्रित, डीफॉल्टने शून्य JS → उत्कृष्ट Core Web Vitals |
| कंटेंट | **Markdown + Content Collections** | लिहायला सोपं, टाइप-सेफ, Git मध्ये आवृत्ती-नियंत्रण |
| स्टाइल | **scoped CSS + design tokens** | अवलंबित्व नाही, हलकं, पूर्ण नियंत्रण |
| प्रतिमा | **`astro:assets` + sharp** | आपोआप WebP/AVIF, रिस्पॉन्सिव्ह `srcset`, lazy-load |
| फॉन्ट | **Mukta + Tiro Devanagari Marathi** (Google Fonts) | देवनागरीसाठी उत्तम वाचनीयता |
| शोध | **client-side JSON index** | सर्व्हरशिवाय, झटपट, खर्चविरहित |
| होस्टिंग | कोणताही static host (Netlify, Vercel, Cloudflare Pages, GitHub Pages) | `dist/` अपलोड करा, झालं |

> **मुख्य CMS हवा असल्यास:** `src/content.config.ts` मधील स्कीमा कायम ठेवून loader
> बदलून Astro सहज एखाद्या headless CMS शी (Sanity, Contentful, Storyblok) जोडता येतं.

## डिझाइन सिस्टम

सर्व टोकन्स `src/styles/global.css` मध्ये CSS custom properties म्हणून एकाच ठिकाणी.

### रंग (Colors)
- **ब्रँड (signature vermillion):** `#b3261e` — विद्याची ओळख
- **पार्श्वभूमी (light):** उबदार कागदी `#fbf9f4`; **dark:** `#14130f`
- **मजकूर:** `--text`, `--text-soft`, `--text-mute` (तीन स्तर)
- **श्रेणी रंग-कोडिंग** (light/dark दोन्हीसाठी ट्यून केलेले):

  | श्रेणी | रंग |
  |---|---|
  | 💼 व्यवसाय | `#1f6f5c` |
  | 💻 तंत्रज्ञान | `#2563eb` |
  | 🚀 स्टार्टअप | `#d9480f` |
  | 🧠 कौशल्ये | `#7c3aed` |
  | 🌱 उद्योजकता | `#0e7490` |
  | 🎓 करिअर | `#b45309` |

### टायपोग्राफी (Type)
- **शीर्षकं:** `Tiro Devanagari Marathi` — मराठीसाठी खास संपादकीय serif
- **मजकूर / UI:** `Mukta` — स्वच्छ, वाचनीय देवनागरी sans
- **टाइप स्केल:** १.२५ (major third) modular scale, `clamp()` ने fluid — `--step--1` ते `--step-5`
- **वाचन-स्तंभ:** ७२ch; ओळ-उंची १.८ (देवनागरीसाठी उदार)

### स्पेसिंग व आकार
- स्पेस स्केल: `--space-3xs` (०.२५rem) … `--space-3xl` (७rem)
- त्रिज्या (radii): `8/14/22px` + `full`
- सावल्या (shadows): `--shadow-s/m/l`

### घटक (Components)
रंग-कोडेड श्रेणी चिप्स · ३-variant लेख-कार्ड · sticky TOC · मुख्य-मुद्दे बॉक्स ·
WhatsApp-first शेअर · थीम-टॉगल (फ्लॅशशिवाय) · रिस्पॉन्सिव्ह नेव्ह · न्यूजलेटर.

### डार्क/लाइट मोड
पहिल्या paint च्या आधी inline script थीम लावतो (फ्लॅश नाही): आधी सेव्ह केलेली पसंती,
नंतर OS ची आवड. हेडरमधल्या बटणाने टॉगल; `localStorage` मध्ये जतन.

## संपादकीय प्रक्रिया

एका विषयाचा प्रवास — वेब संशोधनापासून प्रकाशित मराठी लेखापर्यंत:

```
१. विषय निवड व संशोधन
   → फक्त 6 श्रेणींपैकी एक. जगभरातील ताज्या, विश्वासार्ह स्रोतांचा अभ्यास.
        ↓
२. तथ्य-तपासणी
   → प्रत्येक आकडा/दावा किमान दोन स्वतंत्र स्रोतांशी पडताळा. मत ≠ तथ्य.
        ↓
३. मराठी मसुदा
   → नैसर्गिक, संवादी मराठी (यांत्रिक भाषांतर नाही). रचना:
     शीर्षक + "का वाचावं" + मुख्य मुद्दे + skimmable subheads + "पुढचं पाऊल".
        ↓
४. संपादन व प्रकाशन
   → भाषा/रचना/अचूकता संपादन. स्रोत जोडा, तारीख नमूद करा, प्रकाशित करा.
   → चूक आढळल्यास पारदर्शकपणे दुरुस्त करा.
```

**कधीही प्रकाशित करू नये:** राजकारण, गुन्हेगारी, सेलिब्रिटी गॉसिप, फूट पाडणारं/भडकवणारं,
rage-bait, "धक्कादायक" बातम्या. विषयातून खरं मूल्य मिळत नसेल → प्रकाशितच करू नका.

## नवीन लेख कसा प्रकाशित करावा

1. `src/content/articles/` मध्ये नवी `.md` फाइल तयार करा (फाइलनाव = URL slug).
2. खालील frontmatter भरा:

```yaml
---
title: "तुमचं शीर्षक"
summary: "एक-ओळीचा 'का वाचावं' सारांश."
category: business        # business|technology|startups|learning|entrepreneurship|education
type: guide               # report|guide|analysis|opinion
publishDate: 2026-06-22
tags: ["टॅग१", "टॅग२"]
featured: false           # true → मुख्यपृष्ठावर hero
heroImage: ../../assets/your-image.jpg
heroImageAlt: "प्रतिमेचं वर्णन (a11y)"
takeaways:
  - "मुख्य मुद्दा १"
  - "मुख्य मुद्दा २"
sources:
  - title: "स्रोताचं नाव"
    url: "https://..."
---

लेखाचा मजकूर इथे (## subheads, **bold**, याद्या, > अवतरणं)…
```

3. `npm run dev` ने तपासा → `npm run build` ने तयार करा. बस्स!
   - `draft: true` ठेवल्यास लेख लपतो; भविष्यातील तारीख आपोआप शेड्यूल होते.

## स्थानिक विकास


## SEO, कार्यक्षमता आणि सुलभता

- **SEO:** स्वच्छ URLs, प्रति-पेज meta, Open Graph + Twitter cards, **JSON-LD Article schema**,
  आपोआप **sitemap** आणि **RSS** फीड, canonical URLs.
- **शेअरेबिलिटी:** एक-टॅप **WhatsApp** (मराठी वाचकांसाठी मुख्य), X, Facebook + कॉपी-लिंक.
- **कार्यक्षमता:** डीफॉल्टने शून्य JS, आपोआप WebP/AVIF + रिस्पॉन्सिव्ह प्रतिमा, lazy-load,
  fluid टायपोग्राफी, viewport prefetch → ९०+ Lighthouse चं लक्ष्य.
- **सुलभता (WCAG AA):** semantic HTML, skip-link, keyboard nav, `:focus-visible`,
  alt text, `aria-current`/`aria-live`, `prefers-reduced-motion` चा आदर,
  उत्तम कॉन्ट्रास्ट (light + dark दोन्ही).
